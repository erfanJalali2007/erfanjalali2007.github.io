# پورتفولیو و وب‌سایت شخصی عرفان جلالی (Erfan Jalali Portfolio)
## بسته خروجی کامل و نهایی وب‌سایت (Production Standalone Build)
تاریخ ساخت: ۱۴۰۵/۶/۳۱ (2026-09-22)

این پکیج یک خروجی مستقل، پرسرعت و کامل از وب‌سایت است که بدون نیاز به بیلد مجدد، آماده اجرا و استقرار در تمام سرورها و هاست‌ها می‌باشد.

### محتویات بسته:
- dist/ : خروجی کامل و نهایی وب‌سایت:
  - dist/index.html : صفحه اصلی و لندینگ پیج
  - dist/assets/ : تمام فایل‌های جاوااسکریپت و استایل‌های بهینه‌شده
  - dist/projects/images/ : تمامی تصاویر پروژه‌ها، کاورها و گالری با کیفیت اصلی
  - dist/data/portfolioData.json : دیتای کامل پروژه‌ها، بیوگرافی و اطلاعات تماس
  - dist/server.cjs : سرور مستقل نود برای اجرای اختیاری
- package.json : مشخصات و وابستگی‌ها

### نحوه راه‌اندازی و استقرار (Deploy):
1. **هاست‌های ابری و استاتیک (cPanel, Netlify, Vercel, Liara, GitHub Pages):**
   فقط کافیست تمام فایل‌ها و پوشه‌های داخل پوشه dist/ را به پوشه public_html یا root هاست خود منتقل کنید.
2. **اجرا روی سرور Node.js:**
   دستور `npm start` یا `node dist/server.cjs` را اجرا کنید تا سایت روی پورت 3000 بالا بیاید.
